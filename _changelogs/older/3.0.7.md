# Bountiful Fares Version 3.0.7

Bountiful Fares now requires neoforge version `21.1.219` or greater.

## Fixes
- Fixed Non-Flammable Pickets being smeltable
- Fixed Non-Flammable Pickets and Trellises being burnable
- Added various missing lang entries
- Fixed an incompatibility with InsaneLib that caused falling Coconuts and Walnuts to bug out
- Fixed an issue where falling Walnuts placing on path or farm blocks could reset the count of walnuts in the block

## Changes
- Updated `ru_ru` translations
- Palm Fronds can now be placed onto blocks tagged with `#minecraft:leaves`
- Tweaked the speed of Ceramic Chest close sounds

## Integration
- Fixed missing model for Appledog Block
