# Bountiful Fares Version 3.1.0

## Important
- Bountiful Fares now requires NexusLib version `1.2.1` or greater

## Fixes
- Fixed non-stripped fruit logs not correctly updating neighbors when connecting
- Fixed Ceramic Chests not being in any vanilla item group, they're now found in Functional Blocks
- Fixed a crash associated with Freeze It, and Heat It!

## Changes
- Overhauled Gristmills
  - Milling recipes now support two output slots
    - For some recipes with an output stack greater than 1, this has been split across both slots
    - Other recipes have been given additional products
  - Added a recipe book for Gristmills
    - Recipes will be unlocked when obtaining ingredients like other recipe books

## New Features
- Added new milling recipes for misc resources such as snow, gravel, sand, etc.
- Added Plant Meal
  - A ground up product of crop produce created through many milling recipes, meant to be hoarded in bulk and used to gain additional value from grown crops
  - Milling recipes for flour now also have Plant Meal as a biproduct
  - Can be used in a composter very efficiently compared to their non-processed counterparts (80% chance to increase by a level)
  - Can be used as a fuel to smelt 1.5 items

## Integration
- Gleam
  - Added appropriate light providers for colored light support
