# Bountiful Fares Version 2.0.4

## Fixes
- Fixed Steel Drum Note Block being audible from any distance
- Added missing undying recipes for Ceramic Mosaics and levers
- Fixed ceramic blocks an items potentially rendering incorrectly with shaders
- Fixed growing maize crops crashing the game when using Sinytra

## Compatibility
- Farmer's Delight compat now fully works again
  - Re-added the Walnut and Hoary cabinets
  - Cooking and cutting recipes now function properly
  - New cooking recipes for 2.0.0 have been added - cutting recipes will be added at a later date
- Added a config option to disable compat items from appearing in recipe viewers
- Added the following items to common item tags, and changed their recipes to use common tags:
  - Oranges
  - Lemons
  - Plums
  - Passion Fruit
  - Elderberries
  - Maize (corn tag)
- Added recipe compatibility with:
  - No Man's Land Walnuts
  - Atmospheric Oranges
  - Atmospheric Passion Fruit
  - Environmental Plums
  - Haunted Harvest Corn
- Added compatibility with EMI
  - Fermenting, Milling, Prismarine Propagation, and Bulk ceramic dying recipes can be viewed
  - Added translations for all tags

## Tweaks
- Tweaked the effects for cooking Popped Maize on a Campfire
  - Updated maize popping sound
  - Cooking Popped Maize on a Campfire now emits particles when complete
- Removed Bananacat

## New Features
- Ceramic blocks can now be mass-dyed (thanks to @Diemond_Player)
  - Any number of dye items and a specific ceramic block can be inputted into the crafting grid at any time 
  - This allows you to, say, dye 6 Ceramic Mosaic Stairs with a green, blue, and white dye at the same time
- Crafting variants of ceramic blocks in a Stonecutter will retain it's dyed color (thanks to @Diemond_Player)
- Added ru_ru translations (thanks to @Diemond_Player)
