# Bountiful Fares Version 2.0.4

## Compatibility
- Farmer's Delight compat now fully works again
  - Re-added the Walnut and Hoary cabinets
  - Cooking and cutting recipes now function properly
  - New cooking recipes for 2.0.0 have been added - cutting recipes will be added at a later date
  - Fixed Steel Drum Note Block being audible at the same volume from any distance

## Tweaks
- Tweaked the effects for cooking Popped Maize on a Campfire
  - Updated the popping SFX
  - Cooking Popped Maize on a Campfire now emits particles when complete
- Added missing undying recipes for Ceramic Mosaics and levers
- Removed Bananacat

## New Features
- Ceramic blocks can now be mass-dyed
  - Any number of dye items and a specific ceramic block can be inputted into the crafting grid at any time - this allows you to, say, dye 6 Ceramic Mosaic Stairs with a green, blue, and white dye at the same time
- Crafting variants of ceramic blocks in a Stonecutter will retain it's dyed color
