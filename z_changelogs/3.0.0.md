# Bountiful Fares Version 3.0.0
Farms of Fury or something lmao

## Fixes
- Added Bountiful Fares stairs, slabs and walls to their respective Vanilla block/item tags
- Added missing stonecutting recipes for checkered ceramic mosaic
- Putting undyed ceramic blocks into a stonecutter after dyed ceramic blocks will no longer render the recipes with the previous dyed color
- Chamomile Flowers will now drop extra flowers as items when bonemealed on farmland, instead of cycling back to 1 flower
- Fixed Coconut Cakes not being stackable to 16
- Fixed Sponge Cakes having an incorrect loot table

## Compatibility
- Cake eating sounds will now be played when eating unique mod cakes, particularly Amendments' Double Cake and directional Cake
- Re-implemented Amendments cauldron fluids for Bountiful Fares items
- Updated compatibility with Farmer's Delight:
  - Maize can now be properly planted on Rich Soil Farmland from Farmer's Delight
  - Chamomile and other tea flowers can now be bone mealed on/by Rich Soil Farmland
  - Tomatoes can now be planted on Trellises
- Added compatibility with Appleskin:
  - The food values of items inside Shulker Tiffins will be correctly displayed

## Tweaks
- Added ceramic building blocks to the colored blocks creative tab
- Updated ru_ru translations

## New Features
- Created an official version for NeoForge
- Added Feldspar Brick Wall
- Dyeable ceramic blocks will now show as the closest available map color when on a map
- Added Solid Ceramic
  - Creative mode only block
  - Acts like other dyeable ceramic blocks, but with a solid white texture
  - Available in the creative inventory by enabling the Operator Items tab
- Added Cooked Eggs
  - Made by cooking an Egg...yeah
- Added Coir Bed
  - Crafted from 3 Coconut Coir and 3 planks
  - Will not set the player's spawn point when slept in
- Trellises are now data-driven
  - Trellises are now block entities
  - json files in datapacks under the directory `data/[pack-id]/bountifulfares/trellis_plant` can be used to define new decorative trellis plants
    - The item used to plant it, it's texture, it's model, and whether or not it can be duplicated using Bone Meal can all be defined
      - The "model' field has two options: default or inverted. Inverted is used by Twisting Vines
  - json files in datapacks under the directory `data/[pack-id]/bountifulfares/trellis_crop` can be used to define new trellis crops
    - The seed, result, texture, model, number of stages, chance to grow per random tick, and amount of produce dropped upon harvesting can all be defined
      - The textures for each stage will gain the suffix "_\[stage\]" 
  - For examples on how to create trellis plants and crops, check out the `example_trellis_plants` datapack in the github repository
  - NOTE: This rework will break existing trellises in your world, in particular ones that have plants on them.
- Added Shulker Tiffins
  - Crafted with 2 Shulker Shells and a Bowl
  - Can be dyed all 16 colors
