# Bountiful Fares Version 3.0.0

## IMPORTANT - WHEN UPDATING TO VERSION 3.0.0+
**Updating from a version before 3.0.0 to one after will break a few things in your world:**

**Trellises** - trellises with plants may disappear. It is recommended to break the plants on them before updating.

**Tea Blends** - tea blend items have been removed and their functionality has been replaced by the items they are made of.

## Fixes
- Added Bountiful Fares stairs, slabs and walls to their respective Vanilla block/item tags
- Added missing stonecutting recipes for checkered ceramic mosaic
- Putting undyed ceramic blocks into a stonecutter after dyed ceramic blocks will no longer render the recipes with the previous dyed color
- Chamomile Flowers will now drop extra flowers as items when bonemealed on farmland, instead of cycling back to 1 flower
- Fixed Coconut Cakes not being stackable to 16
- Fixed Sponge Cakes having an incorrect loot table
- Fixed an issue where a Gristmill inventory screen would still exist after its block has been removed
- Pumpkin Pie can no longer be eaten off a Ceramic Dish when "Placeable Pumpkin Pie" is enabled in config
- Wind Charges & Splash/Lingering Water Bottles now properly extinguish Infused/Coconut Candles

## Compatibility
- Cake eating sounds will now be played when eating unique mod cakes, particularly Amendments' Double Cake and directional Cake
- Re-implemented Amendments cauldron fluids for Bountiful Fares items
- Updated compatibility with Farmer's Delight:
  - Maize can now be properly planted on Rich Soil Farmland from Farmer's Delight
  - Chamomile and other tea flowers can now be bonemealed on/by Rich Soil Farmland
  - Tomatoes can now be planted on Trellises
- Added compatibility with Appleskin:
  - The food values of items inside Shulker Tiffins will be correctly displayed

## Tweaks
- Added ceramic building blocks to the colored blocks creative tab
- Updated ru_ru translations
- Removed tea blends
  - Their functionality has been moved to the items that they are made from
- The blocks on which hanging fruit can attach to are now determined by their respective leaves tag
- Added comparator interactivity for several blocks
  - Gristmills give an output based on their combined inventory, similar to Furnaces
  - Ceramic Dishes have unique functionality:
    - When there's nothing in it, it outputs 0
    - When there's an inedible item in it, it outputs 1
    - When there's an edible item in it, it outputs 1-15 based on the nutrition value
  - Trellises produce signals based on their crop:
    - When a crop is planted, it will output 1-15 based on the growth stage
    - When a flower/plant is planted, it will always output 15
    - When empty, it will output 0
  - Fermentation Vessels output 1-15 based on the fermenting time - will max out at 15 when completed
- Changed how Ceramic Dishes drop food item remainders
- Grassy Dirt can now be turned into Dirt Paths & Farmland
- Foods that require Spongekin Slices can now take in Pickled Spongekin as an alternative ingredient
- Grass Seeds can now be made from Short Grass in a Gristmill
- Spongekins can now additionally be sheared with axes

## New Features
- Created an official version for NeoForge
- Added Feldspar Brick Wall
- Dyeable ceramic blocks will now show as the closest available map color when on a map
- Added Solid Ceramic
  - Creative mode only block
  - Acts like other dyeable ceramic blocks, but with a solid white texture
  - Available in the creative inventory by enabling the Operator Items tab
- Added Cooked Eggs
  - Made by cooking an Egg...yeah
- Added Pickled Beetroots
  - Made by fermenting a Beetroot
- Using a dyed Artisan Brush on an Armor Stand with leather armor in a slot will dye the piece
- Right-clicking an Artisan Brush item over a stack of dyeable items (leather armor, wolf armor, ceramic blocks) in an inventory will dye that stack
- Added Flour Blocks
  - Affected by gravity
  - Will create flour particles when being broken, destroyed, exploded, and hit with a Wind Charge
- Added Coir Bed (Thanks to Artyrian)
  - Crafted from 3 Coconut Coir and 3 planks
  - Will not set the player's spawn point when slept in
- Trellises are now data-driven
  - Trellises are now block entities
  - Json files in datapacks under the directory `data/[pack-id]/bountifulfares/trellis_plant` can be used to define new decorative trellis plants
    - The item used to plant it, it's texture, it's model, and whether it can be duplicated using Bone Meal can all be defined
      - The "model' field has two options: default or inverted. Inverted is used by Twisting Vines
  - Json files in datapacks under the directory `data/[pack-id]/bountifulfares/trellis_crop` can be used to define new trellis crops
    - The seed, result, texture, model, number of stages, chance to grow per random tick, and amount of produce dropped upon harvesting can all be defined
      - The textures for each stage will gain the suffix "_\[stage\]" 
  - For examples on how to create trellis plants and crops, check out the `example_trellis_plants` datapack in the github repository
  - NOTE: This rework will break existing trellises in your world, in particular ones that have plants on them.
- Grass Seeds interactions are now data-driven
  - Json files in datapacks under the directory `data/[pack-id]/bountifulfares/grass_seeds_interaction` can be used to define new interactions for grass seeds
    - The soil that the seeds are planted on, what it is converted to, and whether it plants on top (like how Short Grass is planted on top of Grass Blocks) can all be defined
- Spongekin Sprouts will now generate on the floor of sponge rooms in Ocean Monuments, as originally intended
  - Will drop Spongekin Seeds unless broken with Shears or Silk Touch
  - Added Spongekin Sprouts to creative menus
  - Guardians can no longer drop Spongekin Seeds
- Added Shulker Tiffins
  - Crafted with 2 Shulker Shells and a Bowl
  - Can be dyed all 16 colors
  - Up to 64 of any food item can be placed inside, regardless of its stack size
    - If a food with a container is placed inside, its container will be left behind
    - A stack of the food's container needs to be used to take it out
  - Food inside tiffins can be eaten by interacting with the tiffin
  - Any crafting recipe of a food, with its container replaced by a tiffin, will craft that item directly into it
    - Recipes of foods without containers will also work
