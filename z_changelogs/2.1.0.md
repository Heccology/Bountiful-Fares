# Bountiful Fares Version 2.1.0

## Fixes
- Made Pumpkin Pie items inedible when the placeable pumpkin pies config is enabled
- Pumpkin Pie can now be properly pick-blocked in Creative Mode
- Spongekins now drop 3-7 slices when broken
- Several fixes with Farmer's Delight compat:
  - Hoary Logs can be stripped with an axe
  - Straw can once again be collected from Grass and Ferns with the new Grass loot tables
    - This is a fix specifically for this compat; should other mod compats break, you can still disable `grassLootTableOverride` in the config.

## Tweaks
- Added Maize and Leeks to the pig food item tag
- Added all seeds, Walnut, Artisan Cookies, and Walnut Cookies to the parrot food item tag
- Added Pitcher Pods, Hoary Seeds, and Lapisberry Seeds to the sniffer food item tag
- Added Elderberries and Lapisberries to the fox food item tag
- Added Maize to the cow, sheep, and goat food item tags
- Added Oranges, Lemons, Plums, Hoary Apples, and Maize to the horse food item tag
  - Removed mixins relating to animal foods
