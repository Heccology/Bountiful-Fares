# Bountiful Fares Version 2.1.0

## Fixes
- Made Pumpkin Pie items inedible when the placeable pumpkin pies config is enabled
- Pumpkin Pie can now be properly pick-blocked in Creative Mode
- Spongekins now drop 3-7 slices when broken, or themselves with Silk Touch
- Fixed several issues when the player uses items on BF blocks after using an item in the offhand
- Fixed artisan cookies being infinitely edible when holding an artisan cookie
- Mead Bottles now properly return a Glass Bottle when consumed
- Coconut Candles will no longer attempt to be lit again when already lit
- Placing dyed Ceramic Doors now properly applies the color to both halves
- Double Ceramic Mosaic Slabs now properly drop 2 slabs
- Several fixes with Farmer's Delight compat:
  - Hoary Logs can be stripped with an axe
  - Straw can once again be collected from Grass and Ferns with the new Grass loot tables
    - This fix is intended for this compat only; if other mod compats break, you can still disable `grassLootTableOverride` in the config.
- Amendments compat: Double Sponge Cake no longer has a missing model

## Tweaks
- Added Maize and Leeks to the pig food item tag
- Added all seeds, Walnut, Artisan Cookies, and Walnut Cookies to the parrot food item tag
- Added Pitcher Pods, Hoary Seeds, and Lapisberry Seeds to the sniffer food item tag
- Added Elderberries and Lapisberries to the fox food item tag
- Added Maize to the cow, sheep, and goat food item tags
- Added Oranges, Lemons, Plums, Hoary Apples, and Maize to the horse food item tag
  - Removed mixins relating to animal foods
- Spongekins can now be cut on a cutting board with Farmer's Delight installed
- Ceramic blocks can now have their color removed with a Wet Sponge
- Removed bananacat
