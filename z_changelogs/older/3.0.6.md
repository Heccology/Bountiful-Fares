# Bountiful Fares Version 3.0.6

## Fixes
- Fixed Walnut Saplings being in the `flower_pots` block tag instead of Potted Walnut Saplings
- Fixed eating from Shulker Tiffins duplicating containers when eating foods with remainders
- Fixed a crash that happens when eating all food from a Shulker Tiffin and then opening your inventory in creative mode
- Fixed an issue with filling tiffins and painting ceramic with Artisan Brushes from the inventory on dedicated servers
- Fixed an issue where the item pickup animation would play when opening/closing your inventory while holding a Shulker Tiffin
- Fixed Wild Elderberries occasionally generating on Woodland Mansions (as a result of this, Wild Elderberries and Passion Fruit can no longer generate in structures at all)
- Fixed a crash involving Falling Coconuts and world gen

## Changes
- The block loot tables of Oak Leaves and Dark Oak Leaves are no longer completely overriden
- Block loot tables from this mod that reference Shears now use the item tag `c:tools/shear` instead
- Added Leek and Maize Seeds to the `villager_plantable_seeds` item tag
- Hoary Leaves now occasionally drop Hoary Saplings
- Added `vine_crops` item tag, containing all produce created from crops grown on Trellises
- Dyes can now be added and mixed into Artisan Brushes by right-clicking dye items onto the brush in an inventory
- Added various items to additional common item tags

## New Features
- Villagers can now harvest and collect crops that grow on Trellises
- Added Ceramic Chests
  - Can be dyed like other ceramic blocks
  - Dyed ceramic chests will only connect to other ceramic chests with a matching color
  - Has unique open and close sounds (Thanks to Artyrian)
- Added the advancement "No Dirty Dishes"
  - `Craft a food that normally has a container, like a Bowl, directly into a Shulker Tiffin`
